# 农产品图片目录

此目录用于存放农产品的图片文件。

## 图片命名规范

- 主图: `{product_name}1.jpg` (如: longjing1.jpg)
- 详情图: `{product_name}2.jpg`, `{product_name}3.jpg` 等
- 默认图: `default.jpg`
